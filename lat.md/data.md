# Data

Market data is snapshotted to CSV and committed, so the app and CI never depend on a live API.

## Price timeseries

Daily OHLCV for Vodafone (VOD.L) and European/US telecom peers, 5 years, adjusted closes, produced by [[scripts/fetch_data.py#fetch_prices]] from yfinance into `data/prices.csv`. Long format: `Date, Ticker, Open, High, Low, Close, Volume`. Prices are in each listing's local currency (GBp for `.L`), so comparisons use normalised returns.

The file must stay under 1 MiB ([[scripts/fetch_data.py#MAX_BYTES]]) so it can be mounted into Kubernetes as a ConfigMap.

## Vol surface

`data/vol_surface.csv` is a synthetic implied-vol surface generated by [[scripts/fetch_data.py#vol_surface]]: downward-sloping ATM term structure plus skew and smile terms that decay with tenor. LSE single-stock option chains are not available from yfinance, so the surface is illustrative.
